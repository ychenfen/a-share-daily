## 说明

由 GitHub Actions 在每个交易日 16:20 (北京时间) 运行 [scripts/snapshot.py](scripts/snapshot.py) 生成，数据来自腾讯行情和东方财富公开接口。非交易日不写数据，只记一行运行日志。

指数历史由 [scripts/backfill.py](scripts/backfill.py) 一次性回填。涨跌家数、涨停跌停、连板梯队这些是盘后快照，没有历史接口可回填，只能逐日累积，所以回填日期的这几列是空的。
